# Kopi Senja

Aplikasi katalog menu dan pemesanan sederhana berbasis React, Vite, dan Tailwind CSS.

## Menjalankan aplikasi

```bash
pnpm install
pnpm dev
```

Untuk memeriksa build produksi:

```bash
pnpm build
```

Data 15 menu disimpan di `src/data/menu.json`, sedangkan foto menu berada di `src/assets/images/`. Favorit, ulasan, keranjang, dan riwayat transaksi tersimpan di `localStorage` browser.
